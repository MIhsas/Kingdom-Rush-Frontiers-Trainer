# Frontiers 实时修改器实现计划

**目标：** 在独立 Windows 窗口中控制 Frontiers 的击杀金币倍率、金币、钻石、火雨与援军冷却、英雄主动技能冷却及生命。

**架构：** 保留原 main.lua 为新增归档成员，由新的入口调用原入口并装载 Lua 控制模块。C# WinForms 通过本地文本协议发送开关和一次性命令；游戏每帧应用锁定，每 0.2 秒轮询控制。会话标识和五秒租约避免旧命令重放及控制器退出后继续修改。安装检查进程、SHA256、归档 CRC，备份程序和存档。

**技术栈：** 游戏自身 LuaJIT，Python 安装及校验，.NET Framework WinForms。
